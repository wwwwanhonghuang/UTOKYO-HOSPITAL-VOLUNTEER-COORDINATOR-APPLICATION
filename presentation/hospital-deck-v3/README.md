# 学問と実践のあいだに · 第三版

用浏览器打开 [index.html](index.html) 即可查看十五页幻灯片，无须安装或启动服务。请保留整个文件夹，字体、论文和原稿图片均使用本地文件；外部公开记录链接需要网络。

| 操作 | 方法 |
|---|---|
| 前进／后退 | `→`／`←`；空格也可前进 |
| 跳转页面 | `O` 打开十五页目录 |
| 对照日中讲稿 | `N` 打开当前页讲稿 |
| 全屏／打印 | `F`／`P` |
| 关闭当前弹层 | `Esc` 或关闭按钮 |
| 查看原稿细节 | 点击论文图、公式或表格，打开大图 |
| 阅读论文全文 | 点击图注或大图下方的“原文 PDF” |

第 2、5、7—11 页展示实际论文证据。工具栏“文献”进入 [文献与原稿资料页](evidence.html)，可查看 **8 篇本地论文、10 幅原稿摘图及论文首页**；也可直接打开 `assets/papers/` 中的 PDF。原稿大图提供对应 PDF 页码，便于核对上下文。

[speaker_script.md](speaker_script.md) 汇集全部十五页的中文设计意图、日文演讲稿与中文对照；相关页另有论文依据。日文正文约 5,700 字，含指示原稿与停顿时，建议为试讲预留 **约 20—25 分钟**，实际以本人语速为准。

[sources.md](sources.md) 说明每页证据、研究状态，以及原文、转述和岗位实践引申的区分。[evidence_manifest.json](evidence_manifest.json) 记录原稿位置、摘图范围及文件哈希。

本版单独保存。`hospital-deck-v1`、`hospital-deck-v2`、`reference-template` 和Ｒ９申请资料保留原状。

[slides.pdf](slides.pdf) 是十五页定稿，适合直接审阅或发送。PDF 中的文献链接指向公开记录，便于离开原电脑后使用；离线查阅论文及跳转指定页码，请使用 HTML 演示。

# 学問と実践のあいだに

东大医院患者支援团队申请演示 · 第一版 · 2026-10-07

直接用 Chrome、Edge 或其他现代浏览器打开 **[index.html](index.html)**。不需要安装依赖或启动服务器；所需字体、样式、脚本均在此文件夹中，可离线使用。整套文件夹也可以部署到普通静态网站。

- **[逐页演讲稿](speaker_script.md)**：同一个文件包含十五页的设计意图、完整日文稿和中文对照。
- **[静态 PDF](slides.pdf)**：用于逐页审阅、打印或发送；全部内容均已展开。
- **[页面总览](preview/contact-sheet.jpg)**：十五页的缩略图，便于先看全篇节奏。
- **[来源说明](sources.md)**：履历、研究引用、模板与字体来源。

## 操作

| 操作 | 按键 |

| 展开下一组内容／下一页 | →、Space、PageDown |

| 操作帮助 | ? |

点击画面右侧／左侧也可前进／后退。触屏支持左右滑动。地址末尾的 `#14` 可定位第十四页。浏览器的打印功能采用 16:9 页面，请关闭浏览器自带页眉页脚。

## 本版的内容安排

采用原十五页提案。第四页保留第一人称的审美选择，第五、六页保留学问与生存哲学；第七至十一页各展开一个研究问题。第十二、十三页分别说明申请动机和愿意承担的工作。第十四页加入建立 NGO 的理由，明确目前一人自费运营与未来实践场的区别。

日文口述稿约 4,700 字符。按约 16—20 分钟设计，实际用时以本人试讲为准。中文供理解、反馈，不需要在正式演讲时重复朗读。图示用于解释研究问题，其对应的论文状态在每页脚注注明。

沿用参考模板的 1280 × 720 画布、温暖浅粉底色和玫瑰色标题。大句和古典引文使用明朝体；说明文字使用易读的日文字体。标题不加装饰下划线。

## 后续修改

- 修改 `index.html` 的可见正文、`assets/css/style.css` 的版式。
- **演讲稿以 `speaker_script.md` 为单一编辑来源**。修改后执行 `python tools/prepare_assets.py --notes-only`，将相同原稿同步进网页的讲稿面板。
- 如果新增字符在打包字体中不存在，执行 `python tools/prepare_assets.py --font-dir C:/Windows/Fonts` 重建字体子集；需要 Python 与 fontTools，以及 Noto Sans JP / Serif JP / Sans SC 字体。普通查看不需要这些工具。
- 修改后需重新生成 PDF 和页面预览；它们是本版的审阅快照。

本文件夹为独立制作。`../reference-template/`、原提案、R9 申请资料和原 ZIP 均未修改。校验记录保存在 `validation.json`。

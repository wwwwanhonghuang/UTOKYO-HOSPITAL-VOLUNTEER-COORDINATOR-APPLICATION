# 演示策略与逐页设计提案

日期：２０２６年１０月７日。阶段：模板已取回，结构提案；尚未实施新演示。

## 叙事判断

这场演示应让听众理解：一位以全球问题为长期关切的实践学者，如何走到当前的研究与生活位置，以及为何愿意在医院这一具体场域承担工作。演示要保留个人的审美选择、古典引文和学问哲学，也要让患者支援团队理解这个人将如何与同事共事。

建议采用以下主线：

**我走过怎样的道路 → 我如何感受这个时代 → 为什么这种学问与生活对我而言是美的 → 学问如何随问题而显现 → 我的研究在问什么 → 为何来到这里、愿意承担什么 → 长期志向。**

审美判断应当保留其第一人称性质。建议表达为：「この時代、この場所に生きる私には、正義・倫理・関係を問い直す営みが美しく感じられました。」这句话解释个人选择，不能直接推出普遍的道德义务或其他职业的价值等级。进入岗位后如何履行职责，是另一层需要明确说明的问题。建议以「审美上的选择」与「对所承担工作的责任」两层并置，让听众理解其关系。

保留远大志向，同时赋予当下的人和具体工作完整意义。医院中的协作、记录、接待和志愿者支持可以体现严肃的实践学问。叙述重心应落在具体的人与任务上，而不是预先宣称医院将验证某套理论。来自工作的学习应体现为反思自身判断、理解现场，并尊重组织程序与具体人的处境。

## 暂定展示条件

- 主稿１５页，约１５—１８分钟；目前没有已确认的面试时长。这是设计假设。
- 面向日本医院听众，正式画面以日文为主；本提案用中文讨论内容。英文用于必要术语、书名或简短副题。
- 每页一个主问题、一句可记住的观点，以及一个主要图形或两三项内容。
- 主稿之外设置研究文献、项目与技术细节的问答附页，后续按需要制作。
- 如果实际只有１０分钟，可用第１、２、３、４、５、６、７、１２、１３、１４、１５页，研究专题移至问答。

## 逐页设计

| 页 | 暂定日文标题 | 核心内容与拟传达的理解 | 展示方式与讲述重点 |
|---|---|---|---|
| １ | 学問と実践のあいだに | 黄万鴻；东京大学医院患者支援团队申请；副题「関係・正義・ケアをめぐって」。先建立真实、安静、明确的个人声音。 | 大标题、姓名、简短身份与申请对象，大面积留白。口头一句介绍长期关切：如何为人的福祉与更好的共同生活作出贡献。 |
| ２ | これまでの歩み | 大连的工学与日本语教育、东京大学信息理工硕士、ＮＣＮＰ研究、林創研开发、当前独立研究。研究领域变化与实际工作经历清楚可见。 | 双轨时间图：一轨显示教育与研究，一轨显示任职与委托工作，准确表示重叠时期。每个节点只放事实和一项经验；不堆资格列表。 |
| ３ | 私は、この時代をどう見ているか | 从个人观察提出：技术与符号生产扩展之后，信任、主体性、意义与正义为何更引起我的关注。 | 三个连续出现的问题：「何を信頼できるか」「人はどう主体であり続けるか」「何を価値あるものとして生きるか」。明确是本人的时代问题意识；不画未经证明的单向因果链。 |
| ４ | なぜ、いまこの学問へ向かうのか | 直接呈现生涯转向的审美性质：在当下历史时空中，我感到研究哲学、人文与社会科学，尤其正义、伦理、关系，是美的。 | 一句大字日文主张，下面保留「この時代／この関係／私の判断」三个语境词。简洁说明这是个人感受与选择的理由。避免把理由改写成技术领域低于人文学科的价值判断。 |
| ５ | 至道無相、随縁に応じて | 保留「数学家、哲学家、工程师、理论物理学家、神经科学家」的原讲述。理解重点：外界看到的学问姿态，随所面对的问题与关系条件而异。 | 中心写「向き合う問題」，周围五个学问领域随讲述依次出现，每项带一个实际方法或经历：数学工具、哲学框架、软件基盘、场论模型、神经科学研究。画面不把这些称谓列为五项职业资历。主讲稿保留用户提供的口吻。 |
| ６ | 学問にも、縁起がある | 接续长讲稿后半部分：每门学问都有特定时代与关系系统中的缘起；不同问题需要不同方法。要为民生贡献，就不能固执于单一学科；学问本身也具有历史性、关系性、生成性。 | 大字引文「聖人無常心、以百姓心為心」，下方以「人々の生活と問い → 必要な学問・方法 → 応答と学び」作简图。这是对求学姿态的个人理解。 |
| ７ | 人と関係は、どのように生成するのか | 介绍主体性与ＧＲ基础问题：什么使一个主体或关系得以形成、持续与改变？关系、显现以及我们对关系的认识如何区分？ | 一张随时间变化的简明关系图，配一条生活化问题；避免学派缩写树和公式墙。底部标注基础论文候选，具体命题在实施时依照选定论文落实。 |
| ８ | 価値は、どこで生まれるのか | 生成性关系性经济学：研究价值的生成、传递、转换、回流及其历史条件；价格、指标与价值条件之间的区别。 | 一个示意过程：「関わり → 能力・知識・信頼 → 次の活動を可能にする条件」。以日常协作为解释例，不将其写成已经测量的医院经济效果。脚注连接经济学第１４章。 |
| ９ | 支援は、何を可能にするのか | 援助理论关注支持安排如何影响参与、能力与关系的持续；同时保留尊严和援助资格与“是否回报”“是否独立”的区分。 | 中心是一个支持关系，外围呈现资源、参与机会与持续条件。屏幕问题：「支援を受ける人の可能性は、どう広がるか」。详细的援助退出判据放附页，主讲说明有些照护需要持续支持。 |
| １０ | 他者のことが、なぜ私たちにとって重要になるのか | 人道主义理论：他者如何变得可理解、可感、值得关切；某些审美与评价经验如何可能先于明确的义务表达。 | 「出会い・認識／心を動かされる経験／関心／規範・責任」分步出现，画为可能路径，保留多条路径和反馈。讲清“义务如何形成”与“义务是否正当”属于不同研究问题。回扣第４页的个人选择，但不以论文证明自己选择的正确。 |
| １１ | 制度は、経験の何を受け止められるか | 法理学：人的经验进入记录、规则与制度时，哪些方面能被表达，哪些仍需要倾听与判断？ | 「経験 → 記録 → 制度的判断」三栏，下面保留未被充分表达的部分。强调记录的必要性及其边界，连接细致记录与认真理解两种责任。选用可记录性与法律转译论文。 |
| １２ | なぜ、病院でのこの仕事なのか | 将研究关切与本职明确连接：患者、志愿者、职员之间的协作；对生命、健康、福祉与自愿奉献的关切；已有ＵＮＶ／ＳＤＧ３活动经验。 | 三方关系图，中央放「安心して関われる環境」。ＵＮＶ只按已有申请材料说明参加经验；具体任务、时间与证书等信息待证据提供后再扩写。口头说明：希望为这里具体的人承担责任，并在实际协作中深化理解。 |
| １３ | 私が、ここで引き受けたいこと | 从经验走向可承担的工作：信息与记录整理、联络与协作、研修和活动准备、患者服务支持。 | 简洁三列：「これまでの経験／生かせる力／本職での使い方」。研究文书对应记录整理，合作研究与委托开发对应确认、联系、进度共享，ＩＴ经验对应日常事务。明确哪些是已有经历、哪些是拟学习和承担的任务。 |
| １４ | これからの学問と実践 | 哲学、法学相关的进一步深造；日内瓦／哈佛作为用户提出的未来方向；ＮＧＯ实践与理论共同演化；全球问题与人的福祉是长期关切。 | 两个时间尺度：近处是认真承担当前工作、学习现场；远处是进一步深造与ＮＧＯ实践。加一个简洁循环「研究 ↔ 実践 ↔ 理論の修正」。深造标注为计划／志向，具体大学项目、学位与入学时间不代为补定。 |
| １５ | 一人ひとりの幸福へ | 回到整场演示的人与福祉。以个人的学问与生活姿态作结，并向患者、志愿者和职员表达敬意。 | 大面积留白，一句收束：「人々の暮らしに向き合い、学問と実践を深めていきたい。」姓名与联系方式置于角落。若保留「上善若水」作为结尾引文，画面只放短句与出处，展开留给口述。 |

## 讲稿保留方式

第５—６页保留完整的口述空间，预计共２—３分钟。画面承担导航，长讲稿进入演讲者备注。下列中文原稿按用户提供的措辞保存，后续日文口述稿再处理语法和停顿，不擅自改写其哲学立场：

> 一些学者认为本人是数学家，因为自己使用了很多数学工具去研究社会科学。一些学者认为自己是哲学家，因为自己产出许许多多的哲学知见，构建自己的哲学理论框架。一些学者认为自己是工程师，因为工学出身，且构建许多软件基础设施。一些人还认为自己是理论物理学家，场论，时空理论等模型被大量应用在神经科学，社会科学，语言学等领域。有人认为自己是神经科学家，因为曾经研究过神经科学，类脑计算，神经疾病的动力学等领域。，但不论显现哪一个姿态，其都是特定的历史，关系性结构下的要求。中国有一句古话”圣人无常心，以百姓之心为心。“，每一个学问都有特定的时代的关系性系统下的起源的契机（缘起），面对其要解决的问题，合适的方法也不尽相同。因此，期望为民生做出一番贡献，无法执着于一个特定的学问。甚至学问也是生成性关系性存在的。具有历史性，关系性，生成性。

「至道无相，随缘显化」目前按用户的自述格言呈现，不在没有确认出处时标注为古籍原文。「聖人無常心，以百姓心為心」可标注《道德经》第四十九章；用户讲述采用了「百姓之心」的文字形式，正式投影引用时应与所选版本一致。查询参考：[中国哲学书电子化计划](https://ctext.org/text.pl?if=gb&node=11640&show=parallel)。

## 视觉与交互方向

沿用原模板的十六比九画布、温暖浅粉背景、玫瑰色标题、低饱和强调色、逐步显现和键盘翻页。日本语说明使用易读字体，古典引文和核心哲学句使用明朝体。画面以留白和字重建立层次，标题区域不加装饰性下划线。

结构上交替使用：个人时间图、问题页、单句页、古典引文页、关系示意图、具体工作映射页。五张研究页共享相同阅读顺序——一个问题、一个简图、一项研究出处——让不熟悉ＧＲ的听众也能跟上。

每次点击只揭示一个完整意思。开页就可见标题和核心问题；长讲稿保存在演讲者备注，引用出处及研究状态放在不抢占正文的脚注或附页。图示为解释性的示意时应在备注说明，避免被理解为正式公理结构或实证因果图。

后续实现建议保持纯静态站点，增加演讲者备注、整页浏览和打印模式，并本地化必要字体。上述功能在本轮仅规划，未实施。

## 此次调整

封面改为文字扉页；第四页保留完整的个人审美陈述，删除底部三个悬置的词。学问哲学采用引文、短段落和方法索引，研究页明确区分问题与论证层次，不再使用会暗示必然因果、固定阶段或对称角色的节点和箭头。已有经历、拟承担的工作、组织现状与未来愿景分别清楚表述。

配色延续原版的温柔感。标题和古典引文使用柔和玫瑰色，正文为灰紫色，底色为 `#FFF8FA`；版式保持学术讲演与书页的节奏。

十五页日文口述稿与中文对照保持第一版原文，包括第五、六页的学问哲学及第十四页的 NGO 建立理由。只更新每页设计意图，使之对应新版画面。

## 操作

方向键或 Space 展开内容和翻页；**O** 打开目录；**N** 显示当前页讲稿；**F** 全屏；**P** 打印；**Esc** 关闭目录或讲稿。触屏支持左右滑动，地址末尾的 `#4` 可以定位第四页。

## 文件与后续编辑

可见内容在 `index.html`，版式在 `assets/css/style.css`，演讲稿以 `speaker_script.md` 为单一编辑来源。修改讲稿后，执行 `python tools/prepare_assets.py --notes-only` 同步到网页侧栏。新增字符若不在现有字体子集中，可执行 `python tools/prepare_assets.py --font-dir C:/Windows/Fonts` 重建本地字体；需要 fontTools 和已安装的 Noto 字体。普通查看无需这些工具。

PDF 和预览图是此版快照，修改页面后应重新导出。校验记录位于 `validation.json`。

第二版位于独立的 `hospital-deck-v2` 文件夹。第一版、原始参考模板及 R9 申请文件全部保留。
